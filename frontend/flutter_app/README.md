GachaMerch Flutter prototype

Prerequisites:
- Install Flutter SDK: https://flutter.dev/docs/get-started/install
- Ensure `flutter` is on your PATH and run `flutter doctor`.

Run locally:

```bash
cd frontend/flutter_app
flutter pub get
flutter run
```

Notes:
- This is a minimal scaffold. Use `flutter create` if you prefer a full project setup.
- The UI currently lists placeholder SKUs from the product catalog.
